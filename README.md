# make.fun Entry - Bring the Humans

This is a one-page advertisement for make.fun, featuring a personalized referral link (k9r60b8f).

## Deliverables
- `index.html`: The standalone, responsive webpage.
- `ad.png`: A 1280x800 screenshot of the rendered webpage.

## Screenshot Methodology
The `ad.png` was created using a temporary Node.js script with `playwright-core` to render `index.html` in a headless Chromium browser with a viewport size of 1280x800.
